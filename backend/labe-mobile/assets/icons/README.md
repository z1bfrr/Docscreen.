# Diagnostic iOS 26 SVG Icon Pack
24 vector SVG assets: brand logo plus Home, Search, Tests, Labs, Nearby, Home Collection, Reports, Bookings, Favorites, Notifications, Profile, Payments, Orders, Settings, Help, Add, Edit, Delete, Share, Close, Check, Menu and Filter.
All glyph SVGs use `currentColor`, so they can be recolored by the app theme. No raster images are embedded.
